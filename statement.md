# RENTZEN - PROJECT STATEMENT

## 1. Problem Statement

People often need devices such as cameras, laptops, drones, speakers, gaming consoles, and projectors for short-term use but may not want to purchase them. At the same time, many device owners have equipment that remains unused for long periods.

RENTZEN provides a peer-to-peer marketplace where owners can list their devices and renters can discover and rent them. The system simplifies device listing, searching, rental confirmation, rental tracking, and returns through a user-friendly Java GUI.

## 2. Project Scope

The scope of RENTZEN includes:

- User login and account type selection.
- Device listing and marketplace management.
- Searching and browsing available devices.
- Rental confirmation and rental tracking.
- Returning rented devices.
- Owner earnings management.
- Saved devices.
- Role-based access control.
- Input validation and error handling.

The current version is developed as a college-project prototype using in-memory data. Database integration and advanced marketplace features can be added in future versions.

## 3. Target Users

### Device Owners

Users who want to list their unused devices and earn rental income.

### Renters

Users who need devices for temporary or short-term use.

### Owner & Renter Users

Users who want to both rent their own devices and rent devices from other users.

## 4. High-Level Features

- User login with role-based access.
- Browse and search device listings.
- Add and manage personal devices.
- Confirm rentals with a Rental ID.
- Track rental status and history.
- Return rented devices.
- View rental earnings.
- Save devices for future use.
- Automatically add new listings to the marketplace.
- Clear confirmation and error messages.

## 5. Account Roles

### Owner

Can list devices, manage listings, view rental information, and track earnings.

### Renter

Can browse devices, rent available devices, manage rentals, and save devices.

### Owner & Renter

Can access both owner and renter functionalities.

## 6. Technology Used

- Java
- Java Swing
- Java Collections
- Git & GitHub

The application does not require Maven, JavaFX, JavaScript, or third-party libraries.

## 7. Project Objective

The main objective of RentMate is to create a simple and practical peer-to-peer device rental system while demonstrating Java programming, Object-Oriented Programming, GUI development, role-based access control, data handling, validation, and software design concepts.

## 8. Future Scope

Future versions can include:

- MySQL/JDBC database integration.
- Secure authentication and password hashing.
- Online payment gateway.
- Device image uploads.
- Location-based device search.
- Calendar-based availability.
- KYC verification.
- Ratings and reviews.
- Chat between owners and renters.
- Notifications and reminders.
- Admin management system.
